# quanttide-academy

量潮实训基地

## 概述

量潮实训基地，量潮主体档案（`defaults/`）中的实训基地主体，指实训营形态的主体。

## 目录

- `data/`：陈述性记忆——语境、日志、档案、路线图、洞察、意图、报告、参考、历史、宣传册、归档
- `docs/`：程序性记忆——章程、标准、手册、案例集、教程、随笔
- `apps/`：实训项目（`qtgame-tycoon`、`qtgame-weiqi`）
- `examples/`：实验室

`data/` 与 `docs/` 下的子仓库按命名契约 `quanttide-{类型}-of-training-base` 命名，清单见 `.gitmodules`。
